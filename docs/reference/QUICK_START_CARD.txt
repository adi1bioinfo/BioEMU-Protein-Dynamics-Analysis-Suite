  → Fix: pip install MDAnalysis
  → See: docs/TROUBLESHOOTING.md

"FileNotFoundError: trajectory not found"
  → Fix: Check file paths are correct, use absolute paths
  → See: docs/TROUBLESHOOTING.md

"No atoms selected with..."
  → Fix: Verify residue numbers match your structure
  → See: docs/TROUBLESHOOTING.md

"Out of memory"
  → Fix: Increase frame_stride parameter
  → See: docs/TROUBLESHOOTING.md


⚡ PERFORMANCE TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Disable unused analyses (set enabled: False)
• Use conda installation (faster MDAnalysis setup)
• Process data on SSD if possible
• Run on compute cluster for large trajectories
